Kinoko's entire icon set — five hand-drawn mushroom glyphs. Do not substitute Lucide, Phosphor, or emoji.

```jsx
<MushroomIcon variant="spore" color="#B8A5D9" size={36} />
```

`sprout` = growth/types · `spore` = distribution/simulation · `glow` = introspection · `cluster` = storage/queues · `cap` = the general mark. `color` must be a literal hex.
