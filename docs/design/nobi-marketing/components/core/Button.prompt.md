The pill-shaped action; `primary` is the violet-to-mint gradient and should appear once per view.

```jsx
<Button variant="primary" size="lg">Request access →</Button>
```

Variants: `primary` (gradient, mint glow at `lg`), `nav` (violet-to-teal, for the header CTA), `ghost` (outlined), `quiet` (bare, for dialog dismiss). `square` swaps the pill for a 12px radius — that's the form-submit shape. `block` fills the width.
